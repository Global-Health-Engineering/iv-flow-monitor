# Bench Run V_50_05 — 2026-05-13

Fifth and final run of the 2026-05-13 campaign. V_50_05 is the **first independent verification** that `V_CAL_K = 1.27` generalises: the calibration constant was derived from V_50_01..04, then baked into firmware, **then** V_50_05 was captured. V_50_05's per-drop output is not used to fit `V_CAL_K`; it is the closest thing to a holdout-set evaluation the bench day allowed.

## Anomalies / operator notes

- Earlier in the same session the device was repositioned higher on the drip chamber for the backsplash falsifiability test (~16:00 local; see `docs/limitations.md` §3). Before V_50_05 the device was slid back down "slightly" — not all the way to the original V_50_01..03 position. The BOT/TOP pulse ratio of 2.42× here is closer to V_50_02's 2.50× than to V_50_03's 1.87×, suggesting the device is closer to the original (lower) position than to the high-position test.
- Drip rate was steady throughout: 597.5 s / 153 drops = 3.93 s median interval, with no gaps > 2× median. Compare to V_50_04's 15 such gaps.

## Validation outcome

| Comparison | Value |
|---|---:|
| `V_true_chamber` | 51.76 µL |
| `V_est_calibrated` | 41.59 µL |
| `k_post = V_true / V_est_calibrated` | **1.244** |
| Deviation from unity | +24.4 % (device under-reads) |
| V_50_01..04 calibration range of k_post | [0.788, 1.265] |
| V_50_05 inside calibration range? | **Yes** |

### Interpretation

V_50_05's `k_post = 1.244` falls inside the [0.788, 1.265] bracket from V_50_01..04, which means the `V_CAL_K = 1.27` calibration constant — derived from V_50_01..04 — generalises to an independent run within the ±30 % residual band documented in `docs/results.md`. The calibration is not over-fit to the calibration set.

The under-read direction (k_post > 1) is consistent with V_50_01 (1.27), V_50_03 (1.04), and V_50_04 (≥0.89). V_50_02 remains the only over-read run in the campaign. The pattern correlates with drop size: chamber drops above ~50 µL get under-reported, drops below ~40 µL get over-reported. This is the drop-shape oscillation effect (`docs/limitations.md` §1) — bigger drops oscillate further from spherical, so the chord-derived volume biases downward.

### What V_50_05 does NOT validate

- The `V_CAL_K` constant is still board-1, fluid-water, drip-set-X specific. Multi-board, multi-fluid, multi-drip-set generalisation is out of scope for Rev-B.
- Per-drop accuracy is still bounded by the ±30 % residual, not improved by V_50_05. The constant works; the residual structure (drop-shape oscillation) is unchanged.
